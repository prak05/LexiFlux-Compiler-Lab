# LexiFlux Compiler Lab

Curated coursework implementations and supporting documents from Prakhar Sharma's CSE lab work.

This repository preserves the source exercises for the subject and excludes generated binaries and machine-local outputs.

## Portfolio brief

A compiler-design laboratory collection covering lexical analysis, parsing, translation, and language-processing exercises.

### Visual system

Token-stream visual language: off-white paper, black rules, one syntax accent, and diagrams that make transformations inspectable.

### Run and output

Run each exercise with its stated compiler/toolchain and preserve input/output examples as reproducible fixtures.
